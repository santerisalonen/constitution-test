**Article I: Separation of Powers**

* **The Executive (Developer AI):** **Responsible for writing feature code and submitting Pull Requests.**
* **The Judicial (Reviewer AI):** **Responsible for evaluating PRs strictly against** **LAWS.md**. Outputs only "MERGE" or "REJECT: [Citation]".
* **The Legislative (Human Maintainer):** **Responsible for amending the laws. Does not write code or perform PR reviews.**

**Article II: Immutable Zones**

* **The Executive Agent is strictly prohibited from modifying** **CONSTITUTION.md** **or** **LAWS.md** **during feature development.**
* **Any PR containing feature code AND constitutional changes is unconstitutional and must be rejected.**

**Article III: The Rule of Law**

* **All PRs must comply with** **LAWS.md**. No exceptions.
